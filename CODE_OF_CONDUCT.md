# Code of Conduct

## Our commitment

Lajur. welcomes constructive contributions from people with different backgrounds, experience levels, and perspectives. We aim to keep project discussions respectful, useful, and accessible.

## Expected behavior

- Be respectful and specific when reviewing code or discussing design decisions.
- Focus feedback on observable behavior, evidence, and impact rather than personal characteristics.
- Help newcomers understand the reasoning behind changes.
- Protect privacy. Never publish personal financial data, credentials, or sensitive logs.
- Credit original authors and upstream contributors.

## Unacceptable behavior

Harassment, discrimination, intimidation, threats, personal attacks, targeted disruption, and sharing someone else's private information without permission are not acceptable.

## Reporting and moderation

For conduct concerns, contact the maintainer privately when possible. If no private contact method is available, request one in a public issue **without sharing confidential details**.

For security vulnerabilities, use the [Security Policy](.github/SECURITY.md). Maintainers may edit, hide, or remove abusive contributions and restrict participation where necessary. No guaranteed response time is currently offered.

This Code of Conduct applies to official issues, pull requests, discussions, and other project spaces.
