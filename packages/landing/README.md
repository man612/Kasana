# Inherited landing site — not a Lajur. website

This Astro package is **historical marketing material from MoneyMatter**, the upstream project from which Lajur. was adapted. Its pages, cloud offerings, prices, support and community links, policies, analytics settings, social images and feature claims refer to the upstream product. They have **not** been audited or rewritten as claims about Lajur.

The Lajur. application lives in `packages/frontend/` and `packages/backend/`; this landing package is **not** deployed as the Lajur. app. The app's local self-hosting flow does not need this package, and the Lajur. team does not operate the upstream domain. **Do not use this package as a production Lajur. landing site**, point DNS at it, or copy its pricing/policy pages into a new project site.

The inherited layout is marked `noindex` by default to discourage accidental search indexing while its content remains unported. This is not a privacy or access-control mechanism. Before any public landing launch, verify legal rights to imagery, product screenshots, brand claims, checkout and billing, consent and analytics, URLs, app download links, cookie/privacy statements, support contacts, and SEO metadata against the actual Lajur. release. Remove the inherited indexing safeguard only after the content is independently reviewed.
