## Reproduksi dan referensi

Audit statis mencakup definisi route dan pemakai primitif UI. ZIP menyertakan inventaris CSV, tangkapan layar sebelum dan sesudah, serta trace Chromium dengan fixture sintetis. Bukti sebelum menggunakan build lokal terdahulu dengan implementasi UI yang sama. HEAD live dibaca terpisah dari GitHub. Angka frame berasal dari eksperimen lokal Chromium. INP produksi belum diukur.

- Vue 3.5.43 dan Vue Router 5.0.7. Mode `out-in` menunggu leave selesai. Animasi masuk yang singkat mempertahankan konteks tanpa menunda pemasangan rute. [Vue Transitions](https://vuejs.org/guide/built-ins/transition) · [Vue Router Transitions](https://router.vuejs.org/guide/advanced/transitions.html) · [Navigation failures](https://router.vuejs.org/guide/advanced/navigation-failures.html)
- Reka UI 2.9.8 dan VCalendar 3.1.2. Source terpasang menegaskan semantik `select` default di MenuItem, serta pemisahan header, nav dan perhitungan `canMovePrev` di VCalendar. [Reka Dropdown](https://reka-ui.com/docs/components/dropdown-menu) · [VCalendar navigation](https://v3.vcalendar.io/calendar/navigation)
- Vaul Vue 0.4.1. Issue upstream membahas keyboard dan autofocus pada implementasi React, sehingga menjadi konteks. Fakta untuk aplikasi diambil dari viewport dan fokus browser lokal. [Vaul #294](https://github.com/emilkowalski/vaul/issues/294) · [Vaul #605](https://github.com/emilkowalski/vaul/issues/605) · [VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport) · [showPicker](https://developer.mozilla.org/en-US/docs/Web/API/HTMLInputElement/showPicker)
- Playwright 1.60.0. Geometri, scroll, dan daftar fokus diperiksa lewat Chromium. Aksi utama touch menggunakan sasaran produk 44 px jika ruang ada. [ARIA Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) · [Playwright accessibility](https://playwright.dev/docs/accessibility-testing) · [Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines)
